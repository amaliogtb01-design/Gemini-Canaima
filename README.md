# 🚀 Gemini Canaima: IA para todos

Este proyecto nace de una necesidad real: **hacer que la Inteligencia Artificial sea accesible en hardware limitado.**

## 🇻🇪 El Problema
En Venezuela, muchos estudiantes usamos laptops **Canaima**. Estas computadoras tienen recursos limitados (poca RAM), lo que hace que abrir Gemini en un navegador moderno (como Chrome o Firefox) sea muy lento o haga que la computadora se congele.

## 💡 La Solución
He desarrollado un **cliente nativo ligero** usando Python y PyWebView. 
- **Eficiencia:** Consume mucha menos memoria RAM que un navegador.
- **Portabilidad:** Empaquetado en formato **AppImage** para ejecutarse en cualquier distribución Linux sin instalar nada.
- **Enfoque Educativo:** Diseñado para que cualquier estudiante pueda tener a Gemini como una herramienta de estudio siempre a mano.

## 🛠️ Cómo se construyó
Soy un desarrollador de 15 años y creo en el poder de la tecnología. Este software fue diseñado por mí y ejecutado con la ayuda de la propia **IA de Gemini**, demostrando que la Inteligencia Artificial no solo sirve para responder preguntas, sino para **construir soluciones reales.**
